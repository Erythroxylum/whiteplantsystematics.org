# Integrative Plant Systematics Lab website

Jekyll/GitHub Pages starter site for the Integrative Plant Systematics Lab at Texas A&M University.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Open http://127.0.0.1:4000

## GitHub Pages

Repository Settings -> Pages -> Build and deployment -> Deploy from a branch -> main / root.

## Custom domain

The `CNAME` file is set to `whiteplantsystematics.org`. Add DNS records with your domain registrar after GitHub Pages is enabled.
